## Scope

This release keeps transport protocol `1.11` and delivery semantics intact. It:

- embeds WOTR regulation 1.2, including ADR-004 player entry, the adapted
  launcher/one-archive boundary and the mandatory B0 rehearsal after mission
  preparation is explicitly authorized;
- removes former-project labels, repository examples, card prefixes and named
  incident identities from active source/comments, contracts, smoke tests,
  browser/regression tests and structural upstream fixtures;
- replaces product-bearing regression data with neutral `CASEA-*`, `CASEB-*`,
  `CASEC-*`, `example-org/*` and `fixture-*` data while retaining the behavior
  each regression proves;
- makes the portability guard scan the complete ScriptCat tree, including
  contracts, tests, browser tests, regression tests and sanitized upstream
  fixtures, plus current operational guides;
- permits exact imported-repository identity only on two byte-for-byte pinned
  provenance lines in `UPSTREAM.md`; count-only or prose reuse fails;
- updates the current marker-contract example to
  `Creative36711/open-bfme` and rebuilds the userscript from source.
