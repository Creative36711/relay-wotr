# ScriptCat 1.16.7 · tool-call-limit continuation release evidence

Date: 2026-11-21

> Archive note (2026-11-22): this is release evidence kept as an operational record of Open BFME. The
> transport itself — source, bundle, tests, gates and future release notes — now lives in
> `Creative36711/relay-wotr`. Paths named below are read relative to that repository; this record is not
> edited, and no gate in this repository runs them.

Decision: `WOTR-D-021`. Trigger: the Arena warning "the agent reached the tool-call limit
for this turn" was handled correctly — the same turn was continued with the right IDs — but
`C.toolLimitContinueMax` = 2 turned the third occurrence into `tool_limit_paused` and a call
for the Master. That warning is not a failure in the classic sense, so it no longer owns a
counter limit.

Previous local release: `1.16.6`

Local release: `1.16.7` · transport protocol unchanged at `1.11`

## Scope

Delivery semantics are untouched: markers, role profiles, prompt budgets, statuses, Notion and
Drive contracts and the embedded regulation digest stay as they were. `contracts/agent-protocol.json`
gained no key, and no outcome name was removed — `tool_limit_paused` still exists and is still
written for the three real refusals.

- `tools/script-cat/src/01-config.js`: `toolLimitContinueMax` deleted; a comment names the policy.
- `tools/script-cat/src/30-tool-limit.js`: the count comparison is gone from
  `continueToolLimitTurn` and from `continuePilotToolLimit`. `toolLimitContinuations` keeps
  being incremented and recorded (`tool_limit_continued`), so the journal still shows how many
  continuations a turn cost.
- Stays a pause: `tool_limit_no_progress` (after a continuation the agent produced no new
  substantive message, only another limit warning — continuing is pointless), a continuation
  that fails to compile or to deliver, and a live Reviewer card with no continuation template.
- Pace is set by the agent, not by the loop: a continuation requires a new status message
  (`lastToolLimitMessageId`), an unfinished marker and an idle page (`busySettled()`).
- Version bumped in lockstep (D-027): `@version 1.16.7` and the `SCRIPT_VERSION` fallback.

## Release boundary

This release does not change the acceptance oracle of any card, does not turn a `not run` into a
pass, and does not move the cost gates of `docs/agents/cost-gates.md`. The removed counter never
guarded against a runaway loop — progress detection did, and still does; the counter only
stopped healthy long turns, which is the behavior the owner asked to drop.
