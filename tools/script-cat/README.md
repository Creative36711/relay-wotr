# Relay для ScriptCat

Переносимый userscript **1.18.3** ведёт цикл между Coordinator, исполнителем, независимой приёмкой и владельцем через Arena, Notion, Google Drive и GitHub. Проектные адреса живут в импортируемом профиле: каждый проект передаёт свой файл `scriptcat-project-config` (в git транспорта он не входит). Профиль задаёт четыре источника Notion, регламент, единственный репозиторий, базовую ветку и папку Drive. Один профиль — одна активная вкладка; вкладок по контейнерам может быть несколько (см. [Несколько вкладок](#несколько-вкладок)).

Устанавливаемый файл — [relay.user.js](./relay.user.js), его создаёт `node build.mjs` из `src/`, если запустить команду из этого каталога. Название userscript изменено: автоматическое обновление старой записи и доступ к её локальному хранилищу **не гарантированы**. Сначала остановите цикл, сохраните резервную копию и прочтите порядок переноса. Установка сама не создаёт базы и не запускает миссию. Не удаляйте старую установку или историю, пока восстановление не проверено.

Для разработчика: из этого каталога `node build.mjs --check` сверяет сборку. `node portability-guard.mjs` дополнительно читает `../../docs/scriptcat-update.md`. Полный gate из корня: `npm run verify:scriptcat`. Источник и локальная дельта зафиксированы в `UPSTREAM.md`; алиасы отдельных проб не заменяют полный набор тестов.

## Несколько вкладок

Вкладок может быть несколько — по одной на аккаунт-контейнер. Переключать
контейнеры скрипт не умеет, поэтому он не «переносит» вас, а просит остальные
вкладки проснуться:

- **📣 Все вкладки** рядом с «Шаг» и «Включить» — работа запустится в той
  вкладке, для чьей роли она есть. Нажимать можно где угодно, угадывать не надо.
- То же происходит само, когда вкладка поставила задание роли другого аккаунта
  или ушла из-за чужого контейнера либо лимита.
- Отметка живёт 10 минут, повторные нажатия продлевают её не больше чем до 30
  минут подряд. Кнопка ничего не отправляет и не уводит страницу.
- Вкладка отвечает только на свою работу: чужие задания её не трогают.
- Если один аккаунт открыт в двух вкладках, шаг делает только одна, вторая
  ждёт (долгий шаг сам продлевает свою заявку). Соседнему аккаунту это не
  мешает: заявка своя у каждого.
- Пауза и «проект ждёт запуска» остаются за вами: кнопка их не снимает, а
  пишет в журнал, что мешает.
- Задание чужого аккаунта забирает своя вкладка: вкладка, выдавшая ход, к
  чужому контейнеру не переходит. Если нужная вкладка закрыта, в журнале
  сказано, чья она, — откройте её один раз.
- Закрытую вкладку никто не откроет: её нужно открыть один раз в своём
  контейнере.
