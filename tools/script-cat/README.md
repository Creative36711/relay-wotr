# Relay для ScriptCat

Переносимый userscript **1.16.9** ведёт цикл между Coordinator, исполнителем, независимой приёмкой и владельцем через Arena, Notion, Google Drive и GitHub. Проектные адреса живут в импортируемом профиле: для WOTR Remaster используйте `wotr-project.json`. Профиль задаёт четыре источника Notion, регламент, единственный репозиторий, базовую ветку и папку Drive. Один профиль — одна активная вкладка.

Устанавливаемый файл — [relay.user.js](./relay.user.js), его создаёт `node build.mjs` из `src/`, если запустить команду из этого каталога. Название userscript изменено: автоматическое обновление старой записи и доступ к её локальному хранилищу **не гарантированы**. Сначала остановите цикл, сохраните резервную копию и прочтите порядок переноса. Установка сама не создаёт базы и не запускает миссию. Не удаляйте старую установку или историю, пока восстановление не проверено.

Для разработчика: из этого каталога `node build.mjs --check` сверяет сборку. `node portability-guard.mjs` дополнительно читает `../../docs/scriptcat-update.md`. Полный gate из корня: `npm run verify:scriptcat`. Источник и локальная дельта зафиксированы в `UPSTREAM.md`; алиасы отдельных проб не заменяют полный набор тестов.
